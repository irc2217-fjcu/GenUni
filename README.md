# 一般大學-跨域課程模組資源地圖 (GenUni)
### Operational Module OS · 跨域課程與資源拓撲圖譜

本專案為一般大學推動原住民族跨領域學分學程之**資源模組地圖與策略拓撲視覺化系統**。  
前端採用純靜態 Single Page Web App (SPA)，整合 **React 18**、**D3.js 力導向圖形引擎** 與 **Tailwind CSS**，直接透過 **GitHub Pages** 提供永久穩定且免更換網址的線上展示服務；同時直接串接 **Google 試算表** 進行即時數據同步與自動去識別化處理。

任何學校、學程或專案團隊，皆可遵循以下兩大步驟，將過往執行成果轉化為專屬的動態拓撲地圖：

```

│  步驟 1：利用 AI（Gemini / ChatGPT）萃取三年成果報告    │
│  - 輸入「三年成果報告」+「專用 Prompt」+「試算表規格」  │
│  - 明確判定「該校當前發展位階與成熟度」                 │
│  - 自動輸出 35~50 筆節點資料並填入 Google 試算表       │
└────────────────────────────┬────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────┐
│  步驟 2：利用 GitHub 生成分支（Fork）建立專屬拓樸地圖   │
```

### 步驟 1：利用成果報告（至少三年）與 AI 產生節點並判定學校位階

單純憑人工手動整理三年份的厚重成果報告往往費時且容易遺漏。**建議使用具備長文本解析能力的 AI 工具（如 Gemini 1.5 Pro / Advanced 或 ChatGPT Plus）**，搭配我們設計的【專用結構化提示詞（Prompt）】，由 AI 一鍵完成**「資料萃取」**、**「節點比重評定」**與**「該校當前成熟度位階精準判定」**。

#### 💡 學校成熟度位階判定標準（本系統定位模型）：
AI 將依據節點分佈與比重加權，客觀判定貴校當前所處的策略發展位階：
* **階梯一（制度萌芽期 · Phase 1 主導）**：節點多集中於學程行政核備、規章制定與基礎開課，尚未具備高階實作場域或代表作。
* **階梯二（產學技術期 · Phase 2 主導）**：百萬級硬體到位、業界大師入校協同、數位製作與實習成形，正往文化溯源跨越。
* **階梯三（文化深耕期 · Phase 3 主導）**：具備穩固的部落田野、古調採集與族語沉浸機制，形成難以被替代的文化護城河。
* **階梯四（典範輸出期 · Phase 4 主導）**：合輯與 MV 等高規格作品上架、具備跨校巡演影響力，並導入校務 IR 數據精準追蹤就業競爭力。

#### 📋 複製給 Gemini / ChatGPT 的專用提示詞範本（Prompt Template）

> 💡 **使用方式**：
> 1. 打開 **Gemini**（推薦直接上傳 3 年份 PDF/Word 報告）或 **ChatGPT**。
> 2. 複製以下整段提示詞並填入貴校基本資訊，連同成果報告一起送出：

````markdown
你是一位高等教育原住民族跨領域課程模組與資源拓撲分析專家。
請閱讀我所提供的【本校過去至少三年的成果報告／期末結案報告】資料，完成以下兩項任務：

### 【任務一：精確判定本校當前發展階段與位階落點】
請依據三年報告累積的實質成效，對標以下四個成熟度階梯，給出客觀的診斷報告：
1. 階段落點判定：明確指認本校目前主要位處於哪一個階段？（階梯一：制度萌芽期 / 階梯二：產學技術期 / 階梯三：文化深耕期 / 階梯四：典範輸出期），是否有跨階段發展的趨勢？
2. 結構性優勢：分析本校目前高權重（比重 4~5）資產主要集中在何處？
3. 轉型痛點與瓶頸（GAP 分析）：指出本校邁向下一個發展階梯時，目前最欠缺的資源或斷裂的環節。
4. 下一步推進行動建議：具體列出 2~3 項建議優先補足的關鍵里程碑。

---

### 【任務二：萃取 35~50 筆拓撲節點資料（以 Markdown 表格輸出）】
請從三年成果報告中，精準提取 35~50 個核心項目，嚴格依照以下 5 欄規格輸出：
1. 關鍵詞 (ID)：具體項目名稱（10字以內），禁止空泛詞彙，如「百萬級專業錄音室」、「傳統古調流行再造」。
2. 所屬分類 (Group)：必須且只能從以下標籤中擇一歸類：
   - 對應 PHASE 01（建立學程架構）：[行政授權]、[行政瑣務]
   - 對應 PHASE 02（產學技術對接）：[核心主軸]、[技術指標]、[產學對接]、[學習守護]
   - 對應 PHASE 03（文化內涵深耕）：[文化深耕]、[靈魂核心]、[族語教學]、[部落連結]、[社會資本]、[全民原教]
   - 對應 PHASE 04（培育成果驗收）：[學生組織]、[成果驗收]、[績效指標]、[策略輸出]
3. 比重 (Importance)：數值 1 ~ 5，請嚴格按照以下標準給分，且必須呈現金字塔階梯分佈（比重 5 不得超過總數的 15%，比重 1~2 應佔 40% 以上）：
   - 比重 1（基礎維持成本）：例行公文、餐飲便當、耗材採購、差旅核銷等日常剛性維持作業。
   - 比重 2（基礎動員福利）：學生工讀金、招生宣傳、視覺 Logo 等基礎誘因。
   - 比重 3（結構資本協同）：跨院通識對開、校外諮詢委員會、儀式實踐等制度合作。
   - 比重 4（實體核心專業）：百萬專業設備/錄音室、業界大師協作、專業 MV 產製等高階實作。
   - 比重 5（頂層策略優勢）：校級跨域學程規章、稀缺名師資本、民族史觀知識庫、校務 IR 數據治理等不可替代資產。
4. 特性說明：一句話精要說明該項目的核心價值與執行內容（30~50字）。
5. 鏈結關係建議 (Links)：列出 1~3 個有實質合作或連鎖關係的「其他節點名稱」，以半形逗號分隔。（注意：此處提及的名稱必須同時出現在本次表格的 A 欄 ID 中，嚴禁出現幽靈節點）。

請先輸出【任務一：本校當前發展位階判定報告】，接著輸出【任務二：資料表格】。
````

---

#### 💡 提示詞設計避坑清單（本 Prompt 為何如此設計？）：
* **避免節點全部打 5 分**：強制約束「比重 5 不得超過 15%」，確保視覺化圖譜有大小層次，凸顯真正的戰略焦點。
* **避免圖譜連線斷裂（幽靈節點）**：強制約束「Links 內的名稱必須嚴格存在於清單中」，確保 D3 繪圖引擎能完美繪出完整的關聯網絡。
* **避免過於空泛或數量過少**：要求鎖定 35~50 筆節點，確保圖譜物理引力平衡且資訊厚度充足。

#### 📥 將 AI 產出的資料放入 Google 試算表：
1. 開啟 [本系統示範 Google 試算表](https://docs.google.com/spreadsheets/d/17xgU7D08XMKytbgzDQx9-kxOC7eM59QqGklAGN4FTVM/edit)。

5. 複製網址中的 **試算表 ID**（即 `/d/` 與 `/edit` 之間的那串字元）。

### 步驟 2：利用本 GitHub 生成分支（Fork）做出自己的拓樸

不需要重寫任何前端程式碼或 D3 視覺化邏輯，只需透過 GitHub 分支複製即可快速上線：

1. **生成分支／副本（Fork 儲存庫）**：
   - 在本專案右上角點擊 **Fork**（生成分支）。
   - 選擇您的個人帳號或學校組織，點擊 **Create fork**。
2. **替換試算表 ID**：
   - 在您 Fork 的儲存庫中，點選開啟 `index.html`。
   - 點擊右上角鉛筆圖示（Edit this file）進行編輯。
   - 找到 `sheetCsvUrl` 這一行，將試算表 ID 替換成步驟 1 取得的專屬 ID：
     ```javascript
     // 替換為您的專屬 Google 試算表 ID
     const sheetCsvUrl = 'https://docs.google.com/spreadsheets/d/【您的試算表ID】/gviz/tq?tqx=out:csv';
     ```
   - （可選）您也可以在此檔案搜尋並修改網頁標題或自訂文字。
   - 點擊右上角 **Commit changes** 儲存變更。
3. **啟用 GitHub Pages 上線**：
   - 進入儲存庫頂部的 **Settings** ➜ 左側 **Pages**。
   - 在 **Build and deployment** 下方的 **Branch** 選擇 `main`，資料夾保持 `/ (root)`，點擊 **Save**。
   - 等候約 1~2 分鐘，即可獲得您專屬的公開拓樸地圖網址（例如：`https://<您的帳號>.github.io/GenUni/`）！

## 📊 試算表欄位規格 (Google Sheets)

本系統資料庫由標準 5 欄試算表驅動，第一列為標題列，第二列起為資料：

| 欄位代號 | 欄位名稱 | 必填 | 說明與範例 |
| :---: | :--- | :---: | :--- |
| **A 欄** | **關鍵詞 (ID)** | 是 | 節點名稱／活動項目（如：`百萬級專業錄音室`） |
| **B 欄** | **所屬分類 (Group)** | 是 | 對應模組分類標籤（如：`[核心主軸]`、`[技術指標]`、`[行政授權]`、`[文化深耕]`） |
| **C 欄** | **比重 (Importance)** | 是 | 策略重要程度數值（`1` ~ `5`，數值越高圓球越大） |
| **D 欄** | **特性說明** | 否 | 節點之策略定位、成本屬性或執行內涵說明 |
| **E 欄** | **鏈結關係建議 (Links)**| 否 | 跨單位橫向關聯節點，以半形逗號分隔（如：`錄音混音實務培訓, 音樂合輯製作`） |

> 💡 **分類標籤與四大階段自動對齊規則**：
> - `[行政授權]`, `[行政瑣務]` ➜ **PHASE 01: 建立學程架構**
> - `[核心主軸]`, `[技術指標]`, `[產學對接]`, `[學習守護]` ➜ **PHASE 02: 產學技術對接**
> - `[文化深耕]`, `[靈魂核心]`, `[族語教學]`, `[部落連結]`, `[社會資本]`, `[全民原教]` ➜ **PHASE 03: 文化內涵深耕**
> - `[學生組織]`, `[成果驗收]`, `[績效指標]`, `[策略輸出]` ➜ **PHASE 04: 培育成果驗收**

## 🎯 使用與操作指南

### 1. 圖譜視覺化操作
- **畫布縮放**：使用滑鼠滾輪或觸控板手勢放大／縮小圖譜。
- **畫布拖曳**：在空白處按住滑鼠左鍵拖曳，可平移視角。
- **節點探索**：將滑鼠移至節點上並點擊，左下方會彈出「節點詳情卡片」，顯示該節點的權重等級、詳細說明與所屬分類。
- **節點自訂位置**：按住任一節點可拖動改變排列，釋放後彈簧物理引擎會自動重新平衡。

### 2. 側邊欄策略推進導覽
- **展開階段詳情**：點擊左側 PHASE 01 ~ 04 手風琴面板，即可查看各階段之「關鍵執行步驟」與「VRIO 策略核心建議」。
- **快速聚焦節點**：在展開的面板中點選「核心關聯節點」標籤，地圖會立即自動飛入對焦該節點。
- **收合側邊欄**：點擊粉紅色浮動箭頭按鈕，可將左側選單收起，享受全螢幕圖譜視野。

## 🌟 系統特色與架構

1. **D3.js 物理力學互動拓撲**：
   - 節點具備彈性引力與防碰撞機制，支援滑鼠拖曳、滾輪平滑縮放與畫布任意平移。
   - 依節點策略比重（Importance 1 ~ 5）動態調整節點半徑與視覺光暈，重點樞紐一目了然。
2. **四大策略推進階段（Phase）立體架構**：
   - **PHASE 01: 建立學程架構**（藍）：行政授權、通識開課、法規審查與品牌識別。
   - **PHASE 02: 產學技術對接**（綠）：金曲名師協同、百萬錄音室場域、數位混音與實習媒合。
   - **PHASE 03: 文化內涵深耕**（粉）：古調採集、族語沉浸、文化溯源與認同重塑。
   - **PHASE 04: 培育成果驗收**（橘）：創作合輯發行、MV 產製、跨校巡演與校務 IR 追蹤。
3. **策略側邊欄與視角飛入對焦**：
   - 左側磨砂手風琴卡片提供各階段「關鍵執行步驟」與「VRIO 策略核心建議」。
   - 點擊階段或關聯節點標籤時，畫布相機會**自動平滑飛入放大對焦**該核心區域。
4. **雲端試算表零延遲同步**：
   - 前端透過 Google Visualization API (gviz/tq) 支援 CORS 直接拉取試算表 CSV。
   - 後台試算表更新後，前台網頁重整即刻自動生效，毋需重新建置或重新部署。
5. **資料安全與動態去識別化**：
   - 內建一對一即時去識別化過濾（校名替換為示範大學、單位代稱轉譯、隱匿機敏年份）。
   - 具備離線防護機制：若試算表離線或網路中斷，自動切換至內建 45 筆結構化備用數據確保系統永不中斷。
