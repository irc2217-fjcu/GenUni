# 一般大學-跨域課程模組資源地圖 (GenUni)
### Operational Module OS · 跨域課程與戰略資源拓撲圖譜

本專案為一般大學推動原住民族音樂與文化跨領域學分學程之**資源模組地圖與戰略拓撲視覺化系統**。  
前端採用純靜態 Single Page Web App (SPA)，整合 **React 18**、**D3.js 力導向圖形引擎** 與 **Tailwind CSS**，直接透過 **GitHub Pages** 提供永久穩定且免更換網址的線上展示服務；同時直接串接 **Google 試算表** 進行即時數據同步與自動去識別化處理。

## 🌟 系統特色

1. **D3.js 物理力學互動拓撲**：
   - 節點具備彈性引力與防碰撞機制，支援滑鼠拖曳、滾輪平滑縮放與畫布任意平移。
   - 依節點戰略比重（Importance 1 ~ 5）動態調整節點半徑與視覺光暈，重點樞紐一目了然。
2. **四大戰略推進階段（Phase）立體架構**：
   - **PHASE 01: 建立學程架構**（藍）：行政授權、通識開課、法規審查與品牌識別。
   - **PHASE 02: 產學技術對接**（綠）：金曲名師協同、百萬錄音室場域、數位混音與實習媒合。
   - **PHASE 03: 文化內涵深耕**（粉）：古調採集、族語沉浸、文化溯源與認同重塑。
   - **PHASE 04: 培育成果驗收**（橘）：創作合輯發行、MV 產製、跨校巡演與校務 IR 追蹤。
3. **戰略側邊欄與視角飛入對焦**：
   - 左側磨砂手風琴卡片提供各階段「關鍵執行步驟」與「VRIO 戰略核心建議」。
   - 點擊階段或關聯節點標籤時，畫布相機會**自動平滑飛入放大對焦**該核心區域。
4. **雲端試算表零延遲同步**：
   - 前端透過 Google Visualization API (gviz/tq) 支援 CORS 直接拉取試算表 CSV。
   - 後台試算表更新後，前台網頁重整即刻自動生效，毋需重新建置或重新部署。
5. **資料安全與動態去識別化**：
   - 內建一對一即時去識別化過濾（校名替換為示範大學、單位代稱轉譯、隱匿機敏年份）。
   - 具備離線防護機制：若試算表離線或網路中斷，自動切換至內建 45 筆結構化備用數據確保系統永不中斷。

## 🎯 使用與操作指南

### 1. 圖譜視覺化操作
- **畫布縮放**：使用滑鼠滾輪或觸控板手勢放大／縮小圖譜。
- **畫布拖曳**：在空白處按住滑鼠左鍵拖曳，可平移視角。
- **節點探索**：將滑鼠移至節點上並點擊，左下方會彈出「節點詳情卡片」，顯示該節點的權重等級、詳細說明與所屬分類。
- **節點自訂位置**：按住任一節點可拖動改變排列，釋放後彈簧物理引擎會自動重新平衡。

### 2. 側邊欄戰略推進導覽
- **展開階段詳情**：點擊左側 PHASE 01 ~ 04 手風琴面板，即可查看各階段之「關鍵執行步驟」與「VRIO 核心建議」。
- **快速聚焦節點**：在展開的面板中點選「核心關聯節點」標籤，地圖會立即自動飛入對焦該節點。
- **收合側邊欄**：點擊粉紅色浮動箭頭按鈕，可將左側選單收起，享受全螢幕圖譜視野。

## 🚀 部署與維護指引

### GitHub Pages 設定（若需重新啟用）
1. 進入此 GitHub 儲存庫：[https://github.com/irc2217-fjcu/GenUni](https://github.com/irc2217-fjcu/GenUni)
2. 點擊頂部 **Settings** ➜ 左側 **Pages**。
3. 在 **Build and deployment** 下方的 **Branch** 選擇 `main`，路徑選擇 `/(root)`。
4. 點擊 **Save**，稍候片刻即可透過固定網址存取。

### 更換 Google 試算表來源
若未來有新的試算表，只需在 `index.html` 中的 `sheetCsvUrl` 替換新的試算表 ID 即可：
```javascript
const sheetCsvUrl = 'https://docs.google.com/spreadsheets/d/【您的試算表ID】/gviz/tq?tqx=out:csv';
```
*(請確保該試算表之共用權限設為「知道連結的使用者皆可檢視」)*
