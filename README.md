# 一般大學-跨域課程模組資源地圖 (GenUni)
### Operational Module OS · 跨域課程與資源拓撲圖譜

本專案為一般大學推動原住民族跨領域學分學程之**資源模組地圖與策略拓撲視覺化系統**。  
前端採用純靜態 Single Page Web App (SPA)，整合 **React 18**、**D3.js 力導向圖形引擎** 與 **Tailwind CSS**，直接透過 **GitHub Pages** 提供永久穩定且免更換網址的線上展示服務；同時直接串接 **Google 試算表** 進行即時數據同步與自動去識別化處理。

## 🛠️ 如何建立您專屬的拓撲地圖？（快速上手指南）

任何學校、學程或專案團隊，皆可遵循以下兩大步驟，將過往執行成果轉化為專屬的動態拓撲地圖：

```
┌──────────────────────────────────────────────┐
│  步驟 1：萃取成果報告數據（至少三年）        │
│  - 盤點三年報告，提取關鍵節點與鏈結          │
│  - 參考示範試算表評定權重比重（1~5）         │
│  - 建立專屬 Google 試算表並開放檢視          │
└──────────────────────┬───────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────┐
│  步驟 2：利用 GitHub 生成分支建立專屬拓樸    │
│  - Fork 複製此儲存庫到自己的帳號             │
│  - 在 index.html 替換為您的試算表 ID         │
│  - 啟用 GitHub Pages，即可擁有專屬永久網址！ │
└──────────────────────────────────────────────┘
```

### 步驟 1：利用成果報告（至少三年）產生節點與評定比重

為了使拓撲圖譜能真實反映出學程歷年積累的脈絡與深度，**請先彙整貴單位過去「至少三年」的成果報告、期末總結或評鑑資料**進行系統化萃取：

1. **萃取關鍵項目作為節點（Node ID）**：
   - 研讀近三年的成果報告，圈選出重複出現、具指標性或核心里程碑的項目（如：「百萬級專業錄音室」、「傳統古調流行再造」、「校務 IR 精準預警追蹤」等）。
2. **歸類對齊四大策略推進階段（Phase）**：
   - `PHASE 01: 建立學程架構`（藍）：行政審查、通識對開、規章辦法、招生宣傳等。
   - `PHASE 02: 產學技術對接`（綠）：業師協同、錄音室場域、混音實務、業界實習等。
   - `PHASE 03: 文化內涵深耕`（粉）：古調採集、族語工作坊、田野調查、傳統工藝等。
   - `PHASE 04: 培育成果驗收`（橘）：合輯製作、MV 拍攝、巡演發表、就業追蹤等。
3. **評定節點比重（Importance 1 ~ 5）**：
   - **請嚴格參考我們目前的示範試算表標準**：
     - **比重 1（基礎維持成本）**：例行性行政、公文收發、便當餐飲、差旅報銷等維持組織運作之剛性底層作業。
     - **比重 2（基礎動員與福利）**：學生工讀金、招生宣傳、視覺識別 Logo 等基礎參與誘因。
     - **比重 3（結構資本與協同）**：跨院學分對開、諮詢委員會、儀式實踐等制度化合作機制。
     - **比重 4（實體核心與專業賦能）**：專業錄音場域、大師協同工作坊、跨域成果發表展演等核心賦能資產。
     - **比重 5（頂層策略資產與 VRIO 競爭優勢）**：校級學程規章、稀缺大師資本、民族史觀知識庫、校務 IR 數據治理等不可模仿的核心優勢。
4. **填寫專屬 Google 試算表**：
   - 前往 [示範 Google 試算表](https://docs.google.com/spreadsheets/d/17xgU7D08XMKytbgzDQx9-kxOC7eM59QqGklAGN4FTVM/edit) 點選 **「檔案」➜「建立副本」**。
   - 依照下方的[試算表欄位規格](#-試算表欄位規格-google-sheets)填入您的資料。
   - 點擊右上角 **「共用」**，將存取權設為 **「知道連結的使用者皆可檢視」**，並複製網址中的 **試算表 ID**。

### 步驟 2：利用本 GitHub 生成分支做出自己的拓樸

不需要重寫任何前端程式碼或 D3 視覺化邏輯，只需透過 GitHub 分支複製即可快速上線：

1. **生成分支／副本（Fork 儲存庫）**：
   - 在本專案右上角點擊 **Fork**（生成分支）。
   - 選擇您的個人帳號或學校組織，點擊 **Create fork**。
2. **替換試算表 ID**：
   - 在您 Fork 的儲存庫中，點選開啟 `index.html`。
   - 點擊右上角鉛筆圖示（Edit this file）進行編輯。
   - 找到 `sheetCsvUrl` 這一行，將試算表 ID 替換成步驟 1 取得的專屬 ID：
     ```javascript
     // 替換為您的專屬 Google 試算表 ID
     const sheetCsvUrl = 'https://docs.google.com/spreadsheets/d/【您的試算表ID】/gviz/tq?tqx=out:csv';
     ```
   - （可選）您也可以在此檔案搜尋並修改網頁標題或自訂文字。
   - 點擊右上角 **Commit changes** 儲存變更。
3. **啟用 GitHub Pages 上線**：
   - 進入儲存庫頂部的 **Settings** ➜ 左側 **Pages**。
   - 在 **Build and deployment** 下方的 **Branch** 選擇 `main`，資料夾保持 `/ (root)`，點擊 **Save**。
   - 等候約 1~2 分鐘，即可獲得您專屬的公開拓樸地圖網址（例如：`https://<您的帳號>.github.io/GenUni/`）！

## 📊 試算表欄位規格 (Google Sheets)

本系統資料庫由標準 5 欄試算表驅動，第一列為標題列，第二列起為資料：

| 欄位代號 | 欄位名稱 | 必填 | 說明與範例 |
| :---: | :--- | :---: | :--- |
| **A 欄** | **關鍵詞 (ID)** | 是 | 節點名稱／活動項目（如：`百萬級專業錄音室`） |
| **B 欄** | **所屬分類 (Group)** | 是 | 對應模組分類標籤（如：`[核心主軸]`、`[技術指標]`、`[行政授權]`、`[文化深耕]`） |
| **C 欄** | **比重 (Importance)** | 是 | 策略重要程度數值（`1` ~ `5`，數值越高圓球越大） |
| **D 欄** | **特性說明** | 否 | 節點之策略定位、成本屬性或執行內涵說明 |
| **E 欄** | **鏈結關係建議 (Links)**| 否 | 跨單位橫向關聯節點，以半形逗號分隔（如：`錄音混音實務培訓, 音樂合輯製作`） |

> 💡 **分類標籤與四大階段自動對齊規則**：
> - `[行政授權]`, `[行政瑣務]` ➜ **PHASE 01: 建立學程架構**
> - `[核心主軸]`, `[技術指標]`, `[產學對接]`, `[學習守護]` ➜ **PHASE 02: 產學技術對接**
> - `[文化深耕]`, `[靈魂核心]`, `[族語教學]`, `[部落連結]`, `[社會資本]`, `[全民原教]` ➜ **PHASE 03: 文化內涵深耕**
> - `[學生組織]`, `[成果驗收]`, `[績效指標]`, `[策略輸出]` ➜ **PHASE 04: 培育成果驗收**

## 🎯 使用與操作指南

### 1. 圖譜視覺化操作
- **畫布縮放**：使用滑鼠滾輪或觸控板手勢放大／縮小圖譜。
- **畫布拖曳**：在空白處按住滑鼠左鍵拖曳，可平移視角。
- **節點探索**：將滑鼠移至節點上並點擊，左下方會彈出「節點詳情卡片」，顯示該節點的權重等級、詳細說明與所屬分類。
- **節點自訂位置**：按住任一節點可拖動改變排列，釋放後彈簧物理引擎會自動重新平衡。

### 2. 側邊欄策略推進導覽
- **展開階段詳情**：點擊左側 PHASE 01 ~ 04 手風琴面板，即可查看各階段之「關鍵執行步驟」與「VRIO 策略核心建議」。
- **快速聚焦節點**：在展開的面板中點選「核心關聯節點」標籤，地圖會立即自動飛入對焦該節點。
- **收合側邊欄**：點擊粉紅色浮動箭頭按鈕，可將左側選單收起，享受全螢幕圖譜視野。

## 🌟 系統特色與架構

1. **D3.js 物理力學互動拓撲**：
   - 節點具備彈性引力與防碰撞機制，支援滑鼠拖曳、滾輪平滑縮放與畫布任意平移。
   - 依節點策略比重（Importance 1 ~ 5）動態調整節點半徑與視覺光暈，重點樞紐一目了然。
2. **四大策略推進階段（Phase）立體架構**：
   - **PHASE 01: 建立學程架構**（藍）：行政授權、通識開課、法規審查與品牌識別。
   - **PHASE 02: 產學技術對接**（綠）：金曲名師協同、百萬錄音室場域、數位混音與實習媒合。
   - **PHASE 03: 文化內涵深耕**（粉）：古調採集、族語沉浸、文化溯源與認同重塑。
   - **PHASE 04: 培育成果驗收**（橘）：創作合輯發行、MV 產製、跨校巡演與校務 IR 追蹤。
3. **策略側邊欄與視角飛入對焦**：
   - 左側磨砂手風琴卡片提供各階段「關鍵執行步驟」與「VRIO 策略核心建議」。
   - 點擊階段或關聯節點標籤時，畫布相機會**自動平滑飛入放大對焦**該核心區域。
4. **雲端試算表零延遲同步**：
   - 前端透過 Google Visualization API (gviz/tq) 支援 CORS 直接拉取試算表 CSV。
   - 後台試算表更新後，前台網頁重整即刻自動生效，毋需重新建置或重新部署。
5. **資料安全與動態去識別化**：
   - 內建一對一即時去識別化過濾（校名替換為示範大學、單位代稱轉譯、隱匿機敏年份）。
   - 具備離線防護機制：若試算表離線或網路中斷，自動切換至內建 45 筆結構化備用數據確保系統永不中斷。
